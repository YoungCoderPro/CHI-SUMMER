# Photos folder

Drop your place photos in here, then reference them from `data/places.json`, e.g.:

    "photo": "images/ohio-street-beach.jpg"

Suggested: name each file after the place's `id` (e.g. `ohio-street-beach.jpg`) so
they're easy to match up. ~1200px wide is plenty. JPG or PNG both work.

If a photo is missing or the path is wrong, the site shows a colored placeholder tile
with the place's first initial — nothing breaks, so you can add photos gradually.
